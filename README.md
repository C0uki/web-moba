# ミニMOBA — Webで遊べるMOBA

ブラウザだけで遊べる 5 vs 5 のミニMOBAゲームです。ビルド不要・依存ライブラリなし(素のHTML/CSS/JavaScript + Canvas)。

![genre](https://img.shields.io/badge/genre-MOBA-green) ![deps](https://img.shields.io/badge/deps-none-blue)

## 遊び方

### 起動

```bash
# リポジトリ直下で
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

`index.html` をブラウザで直接開いても動きます(ローカルサーバー不要)。

### ルール

- **5 vs 5**(あなた + 味方ボット4体 vs 敵ボット5体)
- ヒーロー選択画面で**自分のレーン(上/中央/下)を選択可能**。top/botレーンは2人ずつ、midは1人の布陣で、残りの味方ボットが自動で埋まる
- ヒーロー選択画面は**ロール(メイジ/ファイター/マークスマン/アサシン/サポート/タンク)で絞り込み可能**
- 3本のレーンにはミニオンが定期的に進軍し、各レーンには**タワーが2本**ずつ
- タワーは外側から順にしか壊せない(内側タワーは無敵表示)
- どこかのレーンのタワーを2本折ると敵**ネクサス**が攻撃可能に
- **敵ネクサスを破壊すれば勝利!** 自陣ネクサスが壊されたら敗北

ミニオンのラストヒットでゴールド、近くの敵の死亡で経験値を獲得。ゴールドは泉(自陣)でアイテムに変えて強くなろう。

### 操作

| 入力 | 動作 |
|---|---|
| 右クリック / 左クリック | 移動(敵の上でクリックすると攻撃) |
| Q / W / E / R | スキル(マウス方向に発動・Rはアルティメット) |
| A | アタックムーブ |
| S | 停止 |
| B | リコール(4.5秒詠唱で拠点へ帰還) |
| P | ショップ(自陣の泉でのみ購入可) |
| マウスホイール | ズーム |
| H | 操作説明 |
| M | ミュート |
| Esc | 一時停止 |

### ヒーロー (30体)

各ヒーローはQ/W/E/R(アルティメット)の4スキルを持つ。ロールは以下の6種類。

| ロール | ヒーロー |
|---|---|
| メイジ | ブレイズ・ナイクス・パイラ・グラシア・ヴォルト |
| ファイター | ソーン・ラグナー・アッシェン・ブルー・ダックス |
| マークスマン | ヴェックス・アリア・ロニン・ミラ・ジーク |
| アサシン | ケストレル・アイビー・ケイド・セイブル・タロン |
| サポート | セラ・リラ・フェイ・オズ・ウィット |
| タンク/イニシエーター | グロム・ボルダー・フロストビアード・ウォーデン・ルーク |

ヒーロー選択画面で各キャラの詳細なスキル説明を確認できる。アルティメット(R)はクールダウンが長い分、大ダメージ・広範囲スタン・チーム全体の回復/シールド・ステルス看破など試合を左右する強力な効果を持つ。

## 構成

```
index.html      エントリHTML
css/style.css   UIスタイル
js/
  utils.js      数学・パス補助
  sound.js      WebAudio効果音
  data.js       定数・ヒーロー・アイテム・レーン定義
  entities.js   ユニット(ミニオン/タワー/ネクサス/ヒーロー)
  ai.js         ボットAI(レーン進軍・交戦・撤退・自動ビルド)
  game.js       ゲーム状態・戦闘・弾・ウェーブ・勝敗
  render.js     Canvas描画・ミニマップ
  ui.js         HUD・ショップ・各種オーバーレイ
  input.js      マウス/キーボード入力
  main.js       起動とメインループ
```
